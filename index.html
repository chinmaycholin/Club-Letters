AI Engine Setup

How to get your API Key:

  1. Go to Google AI Studio.
  2. Sign in with your Google account.
  3. If you do not have a key:
    • Click the "Create API key" button at the top-right of the page.
    • Select a project and click "Create API key".
  4. If you already have a key:
    • Find your key in the list (e.g. "Letter").
    • Click the Copy icon (double-page button) on the right side of the row.
  5. Paste the copied key in the input field above and click save.

Security Note: Your API Key is stored only in your private local browser storage and is sent directly to Google's official Gemini API endpoints.
