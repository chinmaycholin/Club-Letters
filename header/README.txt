=====================================================
The Malnad Technical Club (MTC) - Letter Headers
=====================================================

This folder contains the official headers available in the generator:

1. header.png  -> Normal Club Letterhead
   (Official general letterhead for permissions and club operations)

2. event.png   -> Event Letterhead
   (Official event letterhead for fests, competitions, and workshops)

To update either header in the future:
- Replace "header.png" with your new normal club header image.
- Replace "event.png" with your new event header image when ready.

Recommended specifications:
- Dimensions: 1414 x 2000 pixels (standard A4 ratio 1:1.414)
- Format: PNG
